# Python Lab Assignments

Python Programming Lab Assignments – MIT-WPU

## Assignments

### Assignment 01 – List, Tuple and Dictionary
Different operations on List, Tuple and Dictionary data structures.

### Assignment 02 – Largest of Three Numbers
Python program to find the largest of three numbers using if-else statements.

### Assignment 03 – Right-Angled Triangle
Python program to check whether a triangle is right-angled using a function.

### Assignment 04 – Matrix Addition
Matrix addition using:
- Python Lists
- NumPy Arrays

### Assignment 05 – Strings
Python program to check whether a string contains only alphabets and numbers.

## Technologies Used

- Python
- NumPy
- Jupyter Notebook
- Python IDLE / IDE
